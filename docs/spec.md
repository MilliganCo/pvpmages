# Спецификация Glyph Duel

## Базовые правила

### Размер поля
- **64×48** клеток (параметризовано в `shared/config.ts`)

### Базовые сущности

#### PlayerState
```typescript
{
  hp: number;           // Здоровье
  ink: number;          // Ресурс для рисования
  selectedElement: ElementId | null;  // Текущий выбранный элемент
  ready: boolean;       // Готовность к игре
}
```

#### CellState
```typescript
{
  element: ElementId | null;  // Элемент в клетке или null (пустая клетка)
}
```

### Механика ресурсов

- **HP**: стартовое значение 100
- **Ink**: стартовое значение 100, максимум 100
- **Стоимость рисования**: 1 Ink за изменённую клетку
- **Регенерация Ink**: 10/сек (серверный тик каждые 100ms)
- **Backfire (ошибка распознавания)**:
  - -10 HP себе
  - Кулдаун каста: 500-800 мс (настраивается в config)

### Элементы

Каждый элемент имеет уникальный символ и цвет:

- **Fire (Огонь)**: `#` (красный) - клавиша `1`
- **Water (Вода)**: `~` (синий/циан) - клавиша `2`
- **Earth (Земля)**: `+` (зелёный) - клавиша `3`
- **Air (Воздух)**: `*` (фиолетовый) - клавиша `4`

### Протокол синхронизации

- Сервер — источник истины по HP/Ink
- Отправляются только диффы клеток (`grid_patch`)
- События рисования валидируются на сервере

### Распознавание глифов

Алгоритм (без ML):
1. Выделение связных компонент текущего элемента
2. Выбор самой крупной компоненты
3. Нормализация к фиксированному размеру (16×16)
4. Сравнение с библиотекой эталонов по метрике Dice
5. Порог успеха: `score >= threshold`

### Темп матча

- Длительность: 2-5 минут
- Ритм: рисование → каст → микроконтроль поля → контр-каст
