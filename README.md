# Glyph Duel / Дуэль Глифов

> Public source preview: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known failures and runtime limits.

PvP-игра для локальной сети: два игрока рисуют глифы на матрице символов и сражаются заклинаниями.

## Быстрый старт

1. Установите зависимости:
```bash
npm run install:all
```

2. Запустите сервер и клиент:
```bash
npm run dev
```

3. Откройте в браузере две вкладки:
 <br>
   **Локальное тестирование на одной машине:**
   - `http://localhost:5173/p1`
   - `http://localhost:5173/p2`
 <br>
   Или используйте URL параметры (fallback):
   - `http://localhost:5173?p=1`
   - `http://localhost:5173?p=2`
 <br>
   **Обычный режим (автоматическое назначение ID):**
   - `http://localhost:5173`

4. Оба игрока нажимают "Ready" и начинают дуэль!

## Управление

- **ЛКМ + движение**: рисование на своём поле (непрерывное рисование с интерполяцией линии)
- **1/2/3/4**: выбор элемента (Огонь/Вода/Земля/Воздух)
- **Space**: отправить глиф на распознавание и каст
- **H**: открыть/закрыть справочник глифов (help-меню с превью всех глифов)
- **Escape**: закрыть help-меню

## Структура проекта

- `server/` - Node.js + TypeScript + WebSocket сервер
- `client/` - Vite + React + TypeScript клиент
- `shared/` - общие типы, константы, протокол

## Локальное тестирование (2 вкладки на одной машине)

Для удобного тестирования на одной машине используйте маршруты `/p1` и `/p2`:

1. Запустите `npm run dev`
2. Откройте две вкладки браузера:
   - `http://localhost:5173/p1` (игрок 1)
   - `http://localhost:5173/p2` (игрок 2)
3. Оба игрока нажимают "Ready" и начинают дуэль

Сервер автоматически назначит игрокам соответствующие слоты, если они свободны.
